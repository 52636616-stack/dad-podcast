一、执行摘要

1.1 行业定义

证券行业是金融市场的重要组成部分，主营业务涵盖证券经纪、发行与承

销、自营投资、资产管理、财富管理、研究咨询等。证券公司（券商）作为

资本市场的核心中介机构，承担着价格发现、风险配置、资源配置等关键功

能，是连接实体经济与资本市场的桥梁。

从业务模式看，证券行业经历了从通道业务为主向财富管理+机构业务双轮驱

动的转型。2020年以来，以注册制改革为标志，证券行业进入新一轮发展周

期，头部券商在资本实力、投行能力、财富管理转型等方面展开全面竞争。

1.2 核心观点

1. 资本市场改革持续深化，全面注册制落地重塑行业生态：2023年全面注册

制正式实施，A股IPO节奏经历从加速到收紧的调整，2024年监管层明确”

强本强基”导向，证券公司投行业务从数量扩张转向质量提升，头部券商

投行优势进一步巩固。

2. 财富管理转型是行业最大β，基金代销与投顾业务空间广阔：截至2025年

一季度末，公募基金总规模突破32万亿元，中国居民财富搬家趋势延续，

但基金保有量经历2022-2023年调整后逐步回暖。具备权益类产品销售能

力和投顾服务能力的券商将受益于财富管理赛道红利。

3. 自营业务仍是利润核心，但方向从方向性投资向客需驱动的做市模式转

型：2024年头部券商年化ROE维持在10%-15%区间，自营投资收益贡献约

30%-40%净利润。方向性投资受市场波动影响大，头部券商积极发展场外

衍生品做市、FICC客需业务，降低业绩对市场行情的敏感度。

4. 头部集中趋势加速，“一超多强”格局向”三寡头”演变：中信证券、华泰证

券、中金公司构成第一梯队，2024年净利润合计占行业比重约28%，较

2020年提升约8个百分点。中小券商面临出清压力，部分券商通过特色化

赛道（互联网开户、量化交易、精品投行等）寻求突围。

5. 中资券商国际化加速，港美业务布局进入收获期：中金公司、中信证券、

华泰国际等在港股IPO、跨境并购、衍生品做市等领域的海外收入贡献逐

步提升，中国头部券商已具备与国际顶级投行同台竞争的能力。

二、行业定义与分类

2.1 证券行业定义

根据《中华人民共和国证券法》及《证券公司监督管理条例》，证券公司是

指依照公司法规定设立并经国务院证券监督管理机构批准设立的、从事证券

经营业务的有限责任公司或股份有限公司。

证券行业的主要监管框架包括： - 中国证监会（CSRC）：最高监管机构，负

责证券公司审批、监管规则制定 - 中国证券业协会（SAC）：自律组织，制定

行业规范 - 中证协下的各专业委员会：细分业务自律管理 - 交易所（上交所、

深交所、北交所）：一线监管，交易规则制定

4.3 注册制改革进程与影响

2023年2月17日，全面注册制正式实施，标志着A股IPO体制的根本性变革。

全面注册制的核心变化：

1. 审核机制转变：从”证监会实质性审核”转向”交易所实质审核+证监会注

册”，审核效率提升

2. 上市门槛多元化：允许未盈利企业、红筹企业、特殊股权结构企业上市

3. 定价市场化：新股定价取消23倍市盈率限制，由市场博弈定价

4. 退市制度强化：健全常态化退市机制，2024年强制退市数量创历史新高

全面注册制对证券行业的影响：

• 投行业务：项目数量先增后减（2023年IPO超400家，2024年大幅收紧至约

100家），竞争更加激烈

• 头部效应强化：中信证券、中金公司、华泰联合等头部投行在项目储备和

质量上优势明显

• 质量控制压力加大：监管对投行执业质量要求提升，压实中介机构责任

AI、大数据、云计算等新技术正深刻改变证券行业。头部券商在智能投顾、

十七、行业研究方法论

17.1 证券行业分析框架

本报告采用”宏观-行业-公司”三层分析框架：

宏观层：宏观经济+资本市场+监管政策 - GDP增速、CPI、PPI等宏观指标 - A

股市场走势、成交量、估值水平 - 货币政策、监管政策走向

行业层：行业规模+竞争格局+业务趋势 - 行业总资产、净资产、营收、净利润

- 集中度、业务线条增长趋势 - 政策环境、合规态势

公司层：商业模式+竞争优势+财务表现+估值 - 业务构成、收入结构 - 核心竞

争力、差异化优势 - 盈利能力、资产质量 - PE、PB、EV/EBITDA等估值指标

17.2 券商估值方法

PE估值法： - 适用于盈利稳定的头部券商 - 中信证券历史PE区间：12-25倍 -

目标估值：给予龙头溢价，PE 18-22倍

PB估值法： - 适用于重资本业务占比较高的券商 - 行业PB历史区间：0.8-3.0

倍 - 当前行业PB约1.3倍，处于历史偏低水平 - 目标估值：修复至1.5-1.8倍

P/E+G模型： - 综合考虑盈利和增长 - 公式：PEG = PE / (未来3年净利润复合

增速×100） - PEG<1为低估，PEG>1.5为高估

DDM（股利贴现模型）： - 适用于高分红券商（如中国银河、国泰君安等） -

假设永续增长率和分红率，计算内在价值

分部估值法（SOTP）： - 适用于业务多元化的综合性券商 - 将各业务线条分

部估值后加总 - 例如：中信证券 = 经纪业务×系数 + 投行业务×系数 + 资管业

务×系数 + 自营×系数
