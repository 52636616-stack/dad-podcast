一、行业概述

1.1 全球国防军工格局

当前全球国防军工产业正处于冷战结束以来最深刻的变革期。根据SIPRI（斯

德哥尔摩国际和平研究所）数据，2024年全球国防支出再创历史新高，达到

约2.18万亿美元，同比增长约6.8%。美国以8,860亿美元位居首位，中国以约

2,770亿美元排名第二。

本周重大动态——美国海军换帅事件（2026年4月）：

据观察者网报道，美国海军部长约翰·费伦（John Phelan）于本周被五角大楼

宣布解除职务，成为近期美国军队高层频繁变动中的最新一例。费伦上任仅

一年便遭解职，官方理由是他在”特朗普”级战列舰及”黄金舰队”等海军现代化

项目上”推进不够快”。此次人事变动反映出美国海军当前面临的深层困境：

• 新装备研制困难：星座级护卫舰项目频繁改弦更张，多款新装备出现性能

不达标、成本失控、工期拖延等问题

• 造船工业萎缩：美国修造船工业体系持续萎缩，现有舰船维护保障困难
• 舰龄老化：现役舰船平均舰龄偏大，实际可执行任务的舰艇数量远低于账

面规模

• “特朗普”级战列舰争议：该项目预估造价高达170亿美元，被外界视为”长

官意志一意孤行”的产物

与此同时，中国军工产业正稳步推进现代化进程，在航空航天、海军舰艇、

陆军装备等领域持续取得突破。

2.1 航空装备产业链

2.1.1 军用战斗机

中国空军装备体系持续完善，歼-20隐身战斗机已批量列装部队，歼-35隐身舰

载机研发进展顺利。据国防部公开信息，歼-20已多次在台海方向执行战备巡

航任务。

七、行业发展趋势

7.1 长期趋势

1. 装备更新换代加速：解放军装备现代化进入收获期，三代半、四代装备换

装需求持续释放

2. 信息化、智能化：无人装备、精确打击、网络作战成为发展重点

3. 军民融合深化：民参军门槛降低，优质民企进入军工供应链

4. 国产替代加速：核心零部件自主可控成为刚性需求

7.2 短期催化因素

1. 地缘政治紧张：台海、南海方向军事压力持续存在

2. 国防预算增长：2026年中国国防预算同比增长约7.2%，增速创近年新高

3. 院所改革预期：军工科研院所改制进展持续推进

4. 采购订单释放：2026年一季度主机厂预收款项环比增长明显

7.3 风险提示

1. 订单节奏波动：军工采购具有计划性，部分年份可能出现订单小年

2. 定价机制改革：“成本加成”定价机制改革推进，可能对利润率产生压力

3. 国际形势变化：军贸出口受国际关系影响较大

4. 解禁减持压力：部分公司存在原始股东解禁减持风险
