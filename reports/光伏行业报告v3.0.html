一、执行摘要

1.1 行业核心判断

光伏行业是全球能源转型的核心驱动力，已从”政策补贴驱动”完全转型为”市

场驱动”的无补贴竞争性行业。2025年全球光伏新增装机容量突破500GW大

关，中国市场贡献约60%的全球增量，标志着光伏已成为最便宜的新建电源。

技术迭代加速推进，N型电池（TOPCon、HJT、BC）已全面替代P型PERC，

钙钛矿叠层技术进入商业化前夜。产能阶段性过剩导致产业链价格大幅下

探，淘汰整合正在进行，具备技术壁垒和成本优势的龙头企业集中度持续提

升。

二、行业定义与分类

2.1 光伏发电原理

光伏（Photovoltaic，PV）发电是利用半导体界面的光生伏特效应，将光能直

接转变为电能的过程。当光子照射到金属上时，光子的能量可以被金属中某

个电子全部吸收，电子吸收的能量足够大时，能克服金属内部引力做功，离

开金属表面成为光电子。这一现象在半导体PN结中尤为显著：光照使半导体

内部产生光生载流子（电子-空穴对），在PN结内建电场作用下分离，形成光

生电流和光生电动势。

光伏发电系统核心部件为太阳能电池片（光伏电池），其发电原理具有以下

特点： - 清洁环保：发电过程无燃料消耗、无碳排放、无噪音 - 资源丰富：太

阳能是地球上最丰富的能源，总量约为人类能源需求的1万倍 - 分布广泛：不

受地域限制，可分散布局、近用户侧部署 - 模块化灵活：从瓦级到吉瓦级均可

灵活组合，规模弹性大

2.2 太阳能电池技术分类

太阳能电池按技术代际可分为三大类：

第一代：晶硅电池（c-Si） 晶硅电池是目前市场主流，占全球光伏市场份额约

95%。分为单晶硅和多晶硅两大路线：

• 单晶硅电池：以高纯度单晶硅片为基底，效率高、衰减低、成本较高。

2025年主流P型单晶PERC量产效率约23.5%，N型TOPCon约25.5-26%，

HJT约26.5-27%

• 多晶硅电池：以多晶硅片为基底，效率略低但成本较低，正在快速退出市

场。2025年市场份额已降至5%以下

第二代：薄膜电池（Thin Film） - 碲化镉（CdTe）电池：First Solar主导，理

论效率上限约32%，实际量产效率约19.5%，适合高温环境 - 铜铟镓硒

（CIGS）电池：效率约19-22%，但原材料稀缺限制大规模发展 - 砷化镓

（GaAs）电池：效率极高（30%+），但成本极高，仅用于空间和聚光场景

第三代：新型电池技术 - 钙钛矿电池（Perovskite）：实验室效率突破33.9%

（叠层），成本低、可柔性化，但稳定性和寿命是主要瓶颈 - 有机太阳能电池

（OPV）：效率约15-18%，但寿命问题尚未解决 - 量子点电池：仍处于研发

3.2 全球光伏市场区域分布

中国市场（2025年新增310GW，占全球60%）： 中国是全球最大的光伏市

场，2025年新增装机310GW，同比增长38%。整县推进政策持续深化，户用

光伏、工商业分布式和大型地面电站三大场景共同驱动。西北地区大型风光

大基地项目成为地面电站主要增量，消纳问题逐步通过特高压和储能配套缓

解。

欧洲市场（2025年新增约80GW，占全球15%）： 欧洲2030年气候目标（55%

减排）倒逼新能源加速部署。德国、西班牙、荷兰、波兰和法国是欧洲前五

大市场。2025年欧洲光伏协会（SPE）预计欧洲到2030年每年需新增100GW才

能达标。欧洲《绿色协议》工业战略推动本土制造，但成本劣势短期难以改

变，中国企业通过欧洲本土化产能合作模式应对。

美国市场（2025年新增约60GW，占全球12%）： IRA法案提供十年税收抵

免，推动美国光伏市场超预期增长。2025年美国光伏新增装机约60GW。但对

中国光伏产品的高关税（双反+301条款）形成壁垒，东南亚产能成为主要供

应来源，本土制造也在IRA补贴下加速。洲际贸易摩擦（东南亚反规避调查）

是最大不确定性。

印度市场（2025年新增约30GW，占全球6%）： 印度政府设定2030年500GW

可再生能源目标，光伏是核心抓手。印度对华光伏产品征收基本关税

（BCD），并推出生产挂钩激励（PLI）计划扶持本土制造。印度市场特点是

本土制造能力弱、进口依赖度高，价格敏感性极高。

其他市场（2025年约40GW）： 中东（沙特、阿联酋）、东南亚（越南、泰

国）、拉丁美洲（巴西、墨西哥）是新兴增长极，增速领先但基数较小。

5.2 TOPCon技术深度解析

TOPCon（Tunnel Oxide Passivated Contact，隧穿氧化层钝化接触）是目前性

价比最优的N型量产技术，2025年市场占有率约50%，已取代PERC成为新主

流。

技术原理：在PERC电池背面增加一层超薄氧化硅（约1.5nm）和掺杂多晶硅

层，形成隧穿钝化接触结构，大幅降低背面复合损失，提升开路电压和短路

电流。

核心工艺流程： 1. 硅片清洗制绒 2. 磷扩散/硼扩散（前表面） 3. 背面隧穿氧

化（SiO₂，约1.5nm，LPCVD或PECVD） 4. 背面多晶硅沉积（掺杂非晶硅，

LPCVD或PECVD） 5. 高温退火晶化 6. 金属化（丝网印刷，烧结）

量产数据（2025年主流水平）： - 量产效率：25.5-26.0%（单结晶硅） - 开路

电压（Voc）：720-730mV - 封装功率：580-595W（182尺寸，72片） - 温度系

数：-0.28%/℃（优于PERC的-0.35%/℃） - 双面率：80-85%

TOPCon设备供应商： - 捷佳伟创：LPCVD路线，市场份额约40% - 拉普拉

斯：LPCVD+PEALD，市场份额约30% - 迈为股份：PECVD路线，约20% - 江

苏杰太（PECVD）：约10%

5.3 HJT技术深度解析

HJT（Heterojunction Technology，异质结）采用晶硅和非晶硅的异质结结

构，以其更高的效率上限和简化的工艺流程被视为下一代主流技术。

技术原理：在N型晶硅片两侧沉积本征非晶硅薄膜（i:a-Si）和掺杂非晶硅薄膜

（p:a-Si/n:a-Si），形成PIN结构，利用非晶硅的优异钝化效果降低复合。

HJT核心优势： - 更高的效率上限（理论28.5%，量产可达27%+） - 低温工艺

（≤200℃，节省能耗） - 对称结构，双面发电增益更高 - 低温度系数（-0.23%/

℃），高温环境下发电量优于TOPCon - 可与钙钛矿叠层，缓冲层适配性好

HJT瓶颈： - 设备投资成本高（约为TOPCon的2倍） - 银浆耗量高（是

TOPCon的1.5-2倍） - TCO靶材成本较高 - 量产工艺成熟度较TOPCon仍有差距

主要HJT产能布局企业： - 华晟新能源（全球最大HJT产能，2025年底超

15GW） - 东方日升（2025年HJT产能超5GW） - 通威股份（HJT中试线，2026

年计划大规模量产） - 金刚光伏（薄片化HJT，1.0mm硅片量产）

5.4 BC技术深度解析

BC（Back Contact，背接触）电池是最具差异化的技术路线，其特点是正面

无栅线遮光，背面电极全部集中在背面，理论上效率最高，但工艺最复杂。

1. ABC技术壁垒：ABC技术的图形化、镀膜和金属化工艺均有较高壁垒，爱

4. 技术团队：核心团队来自中科院等科研机构，技术背景深厚

九、风险分析

9.1 行业系统性风险

产能过剩风险：光伏行业历史上经历多轮产能过剩，当前硅料、硅片、电

池、组件各环节均存在阶段性过剩，2026年产能出清仍在进行中，过剩企业

可能面临现金流断裂和退出风险。

产品价格风险：组件价格已从2022年高点的约2.0元/W跌至2025年的约0.7元/

W，跌幅超过60%。若需求增速不及预期，价格可能进一步下探，压制全行业

盈利。

政策变化风险：中国新能源补贴已全面退出，电网消纳瓶颈日益突出；欧美

贸易壁垒持续升级；各国能源政策调整可能影响光伏装机节奏。

9.2 技术路线风险

TOPCon被替代风险：HJT和BC技术若实现成本突破，可能对TOPCon形成替

代。历史上PERC替代BSF仅用了3年（2019-2022年），N型内部的技术替代可

能更快。

钙钛矿商业化风险：钙钛矿稳定性问题尚未完全解决，若GW级量产线暴露严

重稳定性问题，商业化时间表将大幅推迟。

技术专利风险：中国光伏企业在N型技术上与海外存在一些专利争议，若专利

纠纷升级可能影响出口。

9.3 经营风险

汇率风险：海外收入占比约40-60%，人民币汇率波动对业绩影响显著。

原材料价格风险：银浆、IGBT、石英砂等关键辅材价格波动影响成本。

应收账款风险：组件企业赊销模式带来应收账款规模庞大，若下游开发商违

约可能产生坏账。

扩产不及预期风险：部分企业宣布的扩产计划可能因资金、技术或市场变化

而推迟或取消。

9.4 外部环境风险

地缘政治风险：中美贸易摩擦、俄乌冲突等可能影响全球光伏市场发展和中

国企业的海外布局。

电网消纳瓶颈：中国部分地区光伏消纳能力已达极限，弃光率有反弹风险，

影响装机需求。

融资环境变化：光伏企业扩张依赖银行贷款和资本市场融资，若融资环境收

紧，部分高负债企业可能陷入困境。

十、展望与结论

10.1 2026-2030年行业发展展望

规模预测：预计2026年全球光伏新增装机约580-620GW，2030年有望突破

800GW。光伏发电占比将从2025年的约6.5%提升至2030年的约12%。

技术展望： - 2026年：TOPCon量产效率达26.5%+，成为绝对主流；HJT产能

突破100GW；钙钛矿单结百兆瓦线量产 - 2027-2028年：钙钛矿/晶硅叠层GW

级量产；TOPCon+BC（TBC）技术出现；0BB+铜电镀在HJT规模应用 -

2029-2030年：钙钛矿多结叠层商业化；光伏+储能全面平价；BIPV渗透率大

幅提升

竞争格局展望：预计2030年全球组件前十中国企业占据约85%的出货量，中国

光伏制造在全球的主导地位不会根本改变，但贸易壁垒将迫使产能布局更分

散化。

10.2 投资建议总结

增持评级：光伏板块经历大幅调整后，估值具有吸引力。需求端的刚性增长

和供给端的产能出清将为行业复苏奠定基础。

核心配置方向： 1. N型技术红利：晶科能源、钧达股份 2. 一体化稳健龙头：

隆基绿能、晶澳科技 3. 逆变器+储能高增长：阳光电源 4. 设备国产替代+新技

术：迈为股份

风险提示：需关注硅料价格持续低迷、美国关税政策变化、HJT降本不及预期

等风险因素。

15.2 钙钛矿材料特性

钙钛矿材料通式为ABX₃，其中A=有机胺（如CH₃NH₃⁺）或无机铯

三十一、光伏行业历史演进与关键节点

31.1 全球光伏产业发展简史

萌芽期（1950s-1970s）： - 1954年：贝尔实验室首次研发出效率约6%的实用

单晶硅太阳能电池 - 1958年：美国”先锋一号”卫星首次使用硅太阳能电池 -

1970s：太阳能电池开始用于地面，但成本极高（约50美元/W）

成长期（1980s-2000s初）： - 1981年：德国推出全球首个光伏上网电价补贴政

策（KWU计划） - 1991年：日本推出”新阳光计划”，大规模补贴屋顶光伏 -

1997年：德国《上网电价法》（EEG）颁布，成为全球光伏发展里程碑 - 2000

年：德国安装量突破10万千瓦

爆发期（2004-2013）： - 2004年：德国EEG大幅提高补贴，德国光伏市场爆

发式增长，年新增从不足0.1GW增至2012年的约8GW - 2006-2008年：多晶硅

价格暴涨（从约30美元/kg到约500美元/kg），拥硅为王 - 2008-2009年：金融

危机影响，但德国市场补贴退坡缓慢，支撑行业 - 2010年：中国出台光伏补贴

政策（金太阳工程），开启国内市场 - 2011-2012年：欧债危机+双反调查（欧

美对中国光伏产品征收反补贴税），中国光伏出口受挫，行业第一次大规模

整合

调整期（2013-2017）： - 2013年：中国出台《关于促进光伏产业健康发展的

若干意见》，启动标杆上网电价，国内市场加速 - 2013年：欧盟与中国达成光

伏组件最低价格承诺（MIP），贸易摩擦缓和 - 2015年：中国累计光伏装机突

破40GW，成为全球最大市场 - 2016-2017年：分布式光伏政策放开，户用光伏

开始规模化发展
