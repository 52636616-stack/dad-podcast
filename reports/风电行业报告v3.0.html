二、行业定义与分类

2.1 风电行业定义

风电（Wind Power）是通过风力发电机组（Wind Turbine）将风能转化为电能

的可再生能源形式。风电行业覆盖风力发电全生命周期，包括风资源评估、

设备制造（整机、叶片、齿轮箱、发电机、轴承、塔筒等）、建设施工

（EPC）、运营维护以及风电场投资开发等环节。

风力发电原理：风的动能驱动风轮旋转，通过主轴传递至齿轮箱（部分直驱

机型无齿轮箱）增速后驱动发电机发电，所发电力经变流器、升压变压器接

入电网。

2.2 风电分类

2.2.1 按安装位置分类

陆上风电（Onshore Wind）： - 安装于陆地上的风电场 - 技术成熟，建设成本

相对较低 - 2025年全球新增约95GW，占比约79%

海上风电（Offshore Wind）： - 安装于潮间带及近海区域 - 风资源更稳定，

发电利用小时数高（通常比陆上高30-50%） - 单机容量更大

（8MW-15MW+） - 技术难度和建设成本更高 - 2025年全球新增约25GW，占

比约21%，增速显著快于陆上

2.2.2 按技术路线分类

双馈式风电机组（DFIG，Double-Fed Induction Generator）： - 采用齿轮箱

+双馈发电机 - 优点：技术成熟、成本较低 - 缺点：齿轮箱故障率相对较高 -

代表厂商：维斯塔斯、金风科技（部分机型）

直驱式风电机组（Permanent Magnet Synchronous Generator，PMSG）： -

永磁同步发电机，无需齿轮箱 - 优点：可靠性高、维护成本低、发电效率高 -

缺点：发电机成本较高、永磁材料依赖稀土 - 代表厂商：明阳智能、运达股

份、GE（部分机型）

半直驱式风电机组（Hybrid Drive）： - 齿轮箱+永磁同步发电机（低速永磁

同步发电机） - 兼取直驱与双馈优点，平衡可靠性与成本 - 代表厂商：明阳智

能（MySE系列）、西门子歌美飒

三、全球风电市场分析

3.1 全球风电发展历程

全球风电发展经历了三个主要阶段：

第一阶段（1986-2000年）：示范推广期 - 丹麦、美国、德国率先建设首批商

业化风电场 - 单机容量小（30-500kW），成本高昂 - 全球化石能源价格低廉，

风电竞争力不足

第二阶段（2001-2015年）：政策驱动期 - 欧盟率先推行可再生能源配额制 -

德国、西班牙、丹麦形成欧洲风电发展模式 - 金风科技（2007年上市）等中国

企业崛起 - 维斯塔斯、GE、西门子形成三强格局 - 单机容量升级至2-3MW

第三阶段（2016年至今）：市场化发展期 - 陆上风电实现平价上网，摆脱补贴

依赖 - 海上风电技术突破，成为新的增长极 - 中国超过欧洲成为全球最大风电

市场 - 风机大型化加速，成本持续下降

四、中国风电市场深度分析

4.1 中国风电发展历程

4.1.1 早期发展（2005-2012年）：引进吸收期

• 2005年《可再生能源法》颁布实施，风电行业发展有了法律保障
• 金风科技引进德国失速型风机技术，消化吸收后实现国产化
• 早期市场由外资品牌（维斯塔斯、GE、西门子）主导
• 2008-2010年出现”风电三峡”建设热潮
• 2010年新增装机约16GW，累计装机达到44GW

4.1.2 快速发展期（2013-2020年）：国产崛起期

• 国产风机逐步替代外资品牌，金风科技、明阳智能、运达股份等本土厂商

崛起

• 2015年中国风电新增装机达到历史高峰约33GW（陆上）
• 2016-2017年经历抢装后的调整期
• 2019年竞价上网政策出台，行业进入降本压力期
• 2020年陆上风电补贴最后一年，出现抢装潮，新增装机约69GW

4.1.3 平价发展期（2021年至今）：市场化期

• 2021年陆上风电进入平价时代，取消中央财政补贴
• 2022年海上风电进入平价时代（国补退出）
• 风机大型化加速，6MW+机型成为主流
• 2025年预计新增装机85GW（含海上15GW）

5.2 核心零部件分析

5.2.1 叶片

行业地位：叶片是风机的核心捕能部件，其长度和设计直接决定发电效率，

叶片成本占风机总成本约20-25%。

技术趋势： - 长度持续增加：主流叶片长度从120米向150米、180米演进 - 材

十七、风险因素分析

17.1 政策风险

1. 电价政策变化：若风电上网电价大幅下调，将影响风电场项目IRR

2. 补贴退坡风险：地方补贴政策不确定性

3. 土地政策收紧：风电场用地审批趋严

4. 环保政策：鸟类保护、军事协调等可能影响项目进度

17.2 市场风险

1. 风机价格战：行业竞争加剧导致价格大幅下降

2. 装机不及预期：电网消纳能力制约装机增长

3. 原材料价格波动：钢材、铜、稀土等原材料价格大幅波动

4. 国际贸易壁垒：部分国家对中国风电设备设置贸易壁垒

17.3 技术风险

1. 技术路线变化：若半直驱路线全面替代直驱路线，相关企业面临调整

2. 产品可靠性问题：大型化风机运行时间较短，长期可靠性有待验证

3. 核心零部件瓶颈：轴承等核心零部件进口依赖度仍较高

17.4 经营风险

1. 应收账款风险：整机厂商应收账款较高，周转天数约300-400天

2. 现金流压力：风电场开发投资大，现金流压力大

3. 汇率风险：海外业务涉及多币种结算

4. 人才流失风险：核心技术人才竞争激烈

17.5 外部风险

1. 宏观经济下行：电力需求增速放缓影响风电消纳

2. 利率上行：利率上行增加风电项目融资成本

3. 极端天气：台风、结冰等极端天气影响风电场运营

4. 地缘政治：国际局势变化影响风电设备出口

二十、研究结论与投资建议

20.1 核心研究结论

结论一：风电行业处于成长中期，装机增长确定性高

全球碳中和目标驱动，风电作为最成熟的可再生能源技术之一，装机增长确

定性高。2025-2030年全球风电年均新增有望达到150-200GW，中国年均新增

有望达到100-140GW。

结论二：风机大型化是贯穿本轮周期的核心主线

单机容量从4MW跃升至10MW+，度电成本持续下降。叶片长度从150米向200

米+演进，轴承、铸件等核心零部件壁垒持续提升。大型化能力成为整机厂商

核心竞争力。

结论三：海上风电是增速最快的细分领域

海上风电利用小时数高、单机容量大、靠近负荷中心，2025-2030年海上风电

年均增速有望超过25%。明阳智能、电气风电、金风科技三家企业在海上风电

领域具有明显优势。

结论四：中国风电设备出口空间广阔

金风科技、明阳智能、三一重能等企业在手出口订单充沛，东南亚、中东、

欧洲、拉美市场持续突破。中国风电设备性价比优势明显，海外市占率提升

空间大。

结论五：风电运营商业绩稳健，分红能力提升

龙源电力、三峡能源等风电运营商受益于利用小时数提升和绿电溢价，现金

流持续改善，分红能力提升。风电REITs化趋势盘活存量资产，提升估值。
