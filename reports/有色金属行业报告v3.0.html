二、主要品种深度分析

2.1 铜（Copper）

2.1.1 价格走势

• LME三个月期货： $5.6358/lb（约$12,420/吨），周涨幅+2.72%
• SMM现货（1#光亮铜杆）： $13,317.13/吨，升水明显
• 2026年以来铜价整体高位震荡，中东地缘风险推动避险需求，新能源领域

（电动车、充电桩、风电光伏）持续拉动铜消费

2.1.2 供需格局

• 供给端： 全球主要铜矿（智利Escondida、秘鲁Antamina等）产量增速放

缓，印尼、刚果（金）冶炼产能扩张推动TC/RC费用下行，铜精矿供应偏

紧

• 需求端： 中国1-3月新能源汽车累计销量强劲，充电桩保有量同比

+46.9%，电网投资稳健；美国基建计划持续拉动需求

• 库存： LME铜库存近期持续下降，支撑价格

2.1.3 驱动因素

1. 新能源需求爆发： 电动车单车用铜量约80-100kg，充电桩建设提速

2. 电网升级： 全球电网改造、新能源并网带动铜缆需求

3. 矿端干扰： 南美铜矿品位下降，罢工风险持续扰动供给

4. 宏观情绪： 美联储鹰派程度主导美元走势，铜价对货币政策敏感

2.2 铝（Aluminum）

2.2.1 价格走势

• LME铝： $3,314.25/吨，小幅下跌1.21%
• SMM A00铝锭： $3,207.28/吨，升水11.07美元
• 铝价2026年整体在$3,000-3,500/吨区间震荡

2.2.2 供需格局

• 供给端： 中国电解铝产能逼近天花板（4500万吨），“双碳”政策下产能天

花板约束持续，云南等水电铝产能受丰水期影响；印尼氧化铝项目持续推

进

• 需求端： 建筑铝模板、汽车铝车身、光伏铝边框为三大核心需求；中东

地缘风险推动铝价预测上调，但未来数月高价或有所降温

• 成本： 氧化铝价格高企（国内晋豫铝矾土偏紧），电解铝利润空间受挤压

2.2.3 关键变量

1. 电价： 水电铝成本受季节性影响大

2. 氧化铝： 国内铝矾土供应紧张，氧化铝价格强势

3. 出口： 铝材出口受汇率影响，人民币贬值有利出口

4. 库存： 国内铝锭社会库存去化节奏影响现货升贴水

2.3 锂（Lithium）

2.3.1 价格走势

• 电池级碳酸锂： SMM现货$22,752.16/吨，当日+410.99美元（强势上涨）
• 工业级碳酸锂： $22,235.07/吨
• 2026年一季度锂价较2025年低位显著反弹

2.3.2 供需格局

• 供给端： 南美盐湖（Atacama、Olaroz）产量稳步释放，澳大利亚锂辉石

矿进口稳定；非洲锂矿（刚果金、津巴布韦）加速布局；云母提锂在江西

持续扩产

• 需求端： 新能源汽车产销两旺，1-3月中国汽车进口+3%；储能市场爆发

（宁德时代获得全球最大钠电订单60GWh）

• 库存： 中游正极材料厂商年前有备货需求

2.3.3 头部公司业绩（2026年Q1）

• 天齐锂业： Q1营收51.28亿元，同比+98.44%；净利润18.76亿元，同比

+1699.12%，主要受益于锂盐售价大幅上涨及SQM联营公司投资收益增加

• 湖南裕能： Q1营收149.65亿元，同比+121.31%；净利润13.56亿元，同比

+1337.77%，磷酸铁锂正极材料量价齐升

2.4 钴（Cobalt）

2.4.1 价格走势

• 中国钴金属（SMM）： $53,390.02/吨，当日+55.32美元
• 2026年钴价整体在$45,000-60,000/吨区间运行

2.4.2 供需格局

• 供给端： 刚果（金）仍是全球最大钴来源地（占比约70%），供应集中度

高，季节性发货波动较大；印尼镍中间品项目副产钴量稳步增长

• 需求端： 高镍三元电池渗透率提升（镍用量增加、单车钴用量减少），

但整体新能源汽车产销量增长对冲了单车用钴量下降；消费电子（无人

机、电子烟）需求回暖

• 回收： 废旧动力电池回收政策趋严，工信部等五部门联合开展专项执法行

动，规范回收秩序，利好合规回收企业

2.5 稀土（Rare Earths）

2.5.1 供需格局

• 中国主导全球稀土供应链（冶炼分离产能占比约90%）
• 供给端： 稀土开采总量受国家管控，配额制度延续；进口矿（缅甸矿、

美国的芒廷帕斯矿）补充供应

• 需求端： 新能源汽车驱动稀土永磁材料（钕铁硼）需求快速增长；人形

机器人、低空经济等新场景打开增量空间

• 价格： 主流品种（氧化镨钕）2026年价格在底部企稳后有所回升，镝铽

等重稀土相对强势

2.5.2 政策动态

• 商务部对稀土相关物项实施出口管制，推动产业链利润向国内迁移
• 《稀土管理条例》配套细则持续完善，规范化管理加强

四、政策与宏观环境

4.1 国内政策

1. 新能源汽车补贴与购置税减免延续： 继续支撑锂钴镍等新能源金属需求

2. 废旧动力电池回收执法专项行动： 工信部等五部门联合开展，规范化回

收体系建立，有利于有资质的回收企业（宁德时代、格林美、赣锋等）进

一步整合市场

3. 稀土出口管制： 商务部对稀土及其应用技术实施出口管制，抬升全球采

购成本，利好国内产业链利润

4. 充电基础设施： 截至2026年3月，全国充电桩（枪）总数2148.1万个，同

比+46.9%，持续高速增长，直接拉动铜消费

4.2 全球宏观

1. 美联储货币政策： 2026年4月美联储议息会议在即，鲍威尔是否”真正告

别”为市场焦点，鹰派程度将影响美元及大宗商品走势

2. 美国关税政策： 对非USMCA区域墨西哥、加拿大零部件25%关税扰动汽

车供应链，影响铝铜等金属需求

3. 中东地缘冲突： 推高铝价预测，地缘风险溢价计入大宗商品定价

4. 能源转型： 全球碳中和目标推动铜、锂、钴、稀土等绿色金属长期需求

确定性高

五、行业趋势与展望

5.1 短期（2026年内）

• 铜： 矿端偏紧+新能源需求+库存低位，价格维持强势，运行区间

$10,000-14,000/吨

• 铝： 产能天花板约束+氧化铝成本支撑，价格高位震荡，运行区间

$2,800-3,600/吨

• 锂： 供需阶段性错配，中游补库+储能需求爆发，价格偏强，运行区间

$18,000-28,000/吨

• 钴： 供过于求格局边际改善，价格震荡偏强
• 稀土： 政策管控+需求回暖，价格底部企稳回升

5.2 中长期（2027-2030年）

1. 能源转型驱动： 全球碳中和推动铜（电网改造、新能源车）、锂（储

能、电动车）、钴镍（电池）、稀土（永磁电机）需求长期增长

2. 中国资源安全： 稀土、锂、钴等关键矿产对外依存度高，国内矿山开发

提速，政策持续加码

3. 回收产业崛起： 废旧动力电池回收市场爆发，2026年政策专项执法推动行

业规范化，2030年回收锂/钴/镍将贡献显著供应增量

4. 印尼资源枢纽： 镍+钴产业链向印尼集中，形成全球新能源材料”冶炼加工

中心”

5. 固态电池/钠电：下一代电池技术（钠离子电池、固态电池）产业化加速，

宁德时代60GWh钠电订单落地为重要里程碑，可能重塑锂的需求结构

六、风险提示

1. 价格波动风险： 有色金属价格受宏观、地缘、供需多因素影响，波动较

大

2. 政策风险： 国家对矿业、环保、出口管制政策变化

3. 汇率风险： 美元走势影响以美元计价的大宗商品价格

4. 供给增量超预期： 印尼镍、锂项目产能释放可能压制价格

5. 需求不及预期： 全球经济放缓可能拖累有色金属消费
