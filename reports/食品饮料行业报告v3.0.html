中国食品饮料行业报告 v3.0

报告日期：2026年4月28日

一、行业概述

中国食品饮料行业是国民经济的重要组成部分，涵盖白酒、乳制品、调味

品、软饮料、休闲食品等多个细分领域。2024-2025年，行业整体呈现结构性

复苏态势，头部企业强者恒强，中小企业面临整合压力。

1.1 行业规模

• 白酒行业：2024年规模以上企业营收约6,800亿元，头部集中度持续提升
• 乳制品行业：2024年市场规模约5,500亿元，常温白奶增速放缓，低温鲜奶

和功能性乳品增长强劲

• 调味品行业：2024年市场规模约5,000亿元，龙头海天味业市场份额稳居第

一

• 软饮料行业：2024年市场规模约7,000亿元，即饮茶、无糖饮料成为增长引

擎

二、头部企业深度分析

2.1 贵州茅台（600519.SH）

基本情况 - 成立时间：1951年 - 核心产品：飞天茅台、五星茅台、茅台王子酒

等 - 实际控制人：贵州省国资委

财务数据（2024年） - 营业收入：约1,500亿元（同比增长约15%） - 归母净利

润：约750亿元（同比增长约18%） - 毛利率：约92%（核心产品毛利率超

95%） - 每股收益（EPS）：约60元

近期动态（2025-2026年） - 2026年3月，贵州茅台宣布飞天茅台自营体系零售

价涨至1,539元/瓶 - i茅台数字营销平台持续优化，2026年起每人每日可购买12

瓶飞天茅台 - 2025年12月，53度500ml飞天茅台原箱批发参考价跌至1,495元/

瓶，跌破1,499元官方指导价 - 持续推进”酱香化、数字化、国际化”战略

核心竞争力 1. 独一无二的品牌护城河（国家级非物质文化遗产） 2. 稀缺性产

能（赤水河特定产区） 3. 强大的定价权和抗通胀能力 4. 完善的渠道体系（自

营+经销商+数字化平台）

2.2 伊利股份（600887.SH）

基本情况 - 成立时间：1993年（前身呼和浩特市乳品厂） - 核心产品：伊利纯

牛奶、金典有机奶、安慕希酸奶、金领冠婴幼儿配方奶粉、甄稀冰淇淋 - 行业

地位：中国最大、亚洲第一的乳制品企业

财务数据（2024年） - 营业收入：约1,260亿元（同比增长约5%） - 归母净利

润：约100亿元（同比增长约10%） - 毛利率：约33% - 市值：约1,800亿元

业务布局 - 液态奶：伊利纯牛奶、金典（高端）、安慕希（酸奶） - 婴幼儿配

方奶粉：金领冠系列（珍护、育护、菁护等） - 冷饮：甄稀冰淇淋（高端定

位，100%甄选生牛乳） - 原料奶供应：旗下优然牧业运营自有牧场78座，原

料奶产量238万吨，奶牛存栏近50万头

核心优势 1. 全产业链一体化布局（上游牧场到下游渠道） 2. 强大的品牌矩阵

（从大众到高端全覆盖） 3. 覆盖全国的冷链物流网络 4. 持续的研发投入（功

能性乳品创新）

2.3 海天味业（603288.SH）

基本情况 - 成立时间：1984年（前身佛山市海天调味食品公司） - 核心产品：

酱油、蚝油、黄豆酱、酱料、鸡精、味精、醋、料酒 - 行业地位：中国最大、

全球第三大调味品企业

财务数据（2024年） - 营业收入：约250亿元（同比增长约5%） - 归母净利

润：约60亿元（同比增长约8%） - 毛利率：约40% - 市值：约2,500亿元

产品体系 - 酱油系列：海天酱油、金标生抽、草菇老抽等 - 蚝油系列：海天蚝

油、海天0添加蚝油 - 调味酱：海天黄豆酱、海天拌饭酱 - 其他：鸡精、味

精、醋、料酒、酱腌菜

核心优势 1. 酱油产销量连续多年全球第一 2. 覆盖全国的销售网络（600+个销

管中心） 3. 规模化生产带来的成本优势 4. 强大的渠道掌控力（KA+餐饮+电

商全渠道）

2.4 蒙牛乳业（2319.HK）

基本情况 - 成立时间：1999年 - 核心产品：特仑苏（高端白奶）、纯甄酸奶、

冠益乳、妙可蓝多奶酪 - 行业地位：中国第二大乳制品企业

财务数据（2024年） - 营业收入：约1,100亿元（同比增长约6%） - 归母净利

润：约50亿元（同比增长约12%） - 毛利率：约35%

核心产品 - 特仑苏：中国高端白奶第一品牌，有机奶和纯牛奶两大系列 - 纯

甄：常温酸奶龙头产品 - 妙可蓝多：奶酪棒市场领导者（2021年完成对妙可蓝

多的收购）

2.5 农夫山泉（9633.HK）

基本情况 - 成立时间：1996年 - 核心产品：农夫山泉饮用天然水、东方树叶无

糖茶、尖叫功能饮料、水溶C100、NFC果汁 - 行业地位：中国最大饮用水企

业，包装饮用水市场份额第一

财务数据（2024年） - 营业收入：约400亿元（同比增长约25%） - 归母净利

润：约100亿元（同比增长约30%） - 毛利率：约60%（茶饮料毛利率超65%）

增长引擎 1. 东方树叶：无糖茶饮市场爆发，2024年增速超50% 2. 尖叫：功能

饮料市场稳健增长 3. 水溶C100：果汁饮料差异化竞争 4. 包装饮用水：持续巩

固市场领导地位

2.6 娃哈哈集团

基本情况 - 成立时间：1987年 - 创始人：宗庆后（2024年2月逝世） - 核心产

品：AD钙奶、营养快线、纯净水、八宝粥、爽歪歪 - 行业地位：中国饮料行

业龙头企业

近期动态 - 2024年宗馥莉接任集团副董事长兼总经理，推进年轻化转型 - 推出

无糖茶新品，拓展健康饮品赛道 - 加大电商渠道投入，探索新零售模式

核心优势 1. 经典产品AD钙奶、营养快线畅销20余年 2. 强大的下沉市场渠道网

络 3. 国民品牌情怀优势 4. 丰富的产品线覆盖多品类

四、行业趋势与展望

4.1 消费趋势

1. 健康化：0添加、低糖、低脂、高蛋白成为标配

2. 品质化：消费者愿意为高端、差异化产品支付溢价

3. 便捷化：即食、便携包装需求增长

4. 情感化：品牌故事、文化内涵成为重要竞争要素

4.2 渠道趋势

1. 电商渗透率提升：直播电商、社区团购重塑渠道格局

2. O2O融合：即时零售（美团、饿了么）成为重要增量渠道

3. 私域运营：企业微信、小程序私域流量运营深化

4. 下沉市场：三四线城市及农村市场成为增长新动能

4.3 数字化趋势

1. 数字营销：i茅台等数字化销售平台重塑白酒销售模式

2. 智慧供应链：区块链技术溯源、自动化仓储提升效率

3. 数据中台：消费者洞察驱动产品研发和精准营销

4.4 出海趋势

1. 白酒国际化：茅台、五粮液加大海外市场投入（主要针对华人社区）

2. 茶饮出海：喜茶、奈雪的茶在东南亚、欧美开设门店

3. 乳制品出口：伊利、蒙牛拓展东南亚、大洋洲市场

五、主要风险因素

5.1 宏观风险

• 消费复苏不及预期
• 原材料价格波动（牛奶、白糖、农产品）
• 食品安全事件冲击

5.2 行业风险

• 人口出生率下降影响婴幼儿配方奶粉需求
• 竞争加剧导致价格战
• 监管政策变化（酒类营销限制、保健品监管）

5.3 企业风险

• 渠道库存积压
• 品牌老化风险
• 多元化扩张失败风险

七、总结

中国食品饮料行业在2024-2025年呈现结构性复苏特征：

• 白酒：高端化趋势持续，茅台龙头地位稳固，但批价波动需关注
• 乳制品：常温白奶增速放缓，低温鲜奶、功能性乳品成为新增长点
• 调味品：行业稳健增长，龙头企业凭借品牌和渠道壁垒强者恒强
• 软饮料：无糖化、健康化趋势明显，新品类爆发式增长

展望未来，食品饮料行业将持续受益于消费升级和健康化趋势，头部企业凭

借品牌、渠道、规模优势有望延续强者恒强格局。建议重点关注具备品牌护

城河、产品创新力和渠道掌控力的龙头企业。
